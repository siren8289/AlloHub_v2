# 데이터전처리 코드검증

- 범위: ALH-0713 ~ ALH-0760 (48건)
- 대상: `data/etl/transform.py`. 모델 입력 제외는 힌트 파일 밖인 `ai/src/scoring/features.py`를 봤다.
- 방법: 소스 대조. `to_number`, `count_by_crno`, `latest_dividend`, `build_companies`를 작은 픽스처로 실행했다. 공개 API는 호출하지 않았다.
- 판정: 통과 44, 실패 3, 부분 1, 확인불가 0

## 실패·부분

- ALH-0722 실패. `dividend_count` 컬럼이 없다. 배당 0건은 `has_dividend=0`일 뿐이고 건수 필드로 남기지 않는다.
- ALH-0723 실패. 배당 1건도 `dividend_count`가 아니라 `has_dividend=1`이다.
- ALH-0724 실패. 배당 3건은 최신 1건만 남아 `has_dividend=1`이다. 3으로 세지 않는다.
- ALH-0742 부분. 같은 `basDt`면 `>=`라서 나중에 순회한 행이 이긴다. 공시번호 같은 2차 키가 없어 입력 순서가 바뀌면 다른 배당이 선택된다.
