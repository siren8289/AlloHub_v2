# ML모델추론 코드검증

- 범위: ALH-0435 ~ ALH-0456
- 대상: `ai/src/scoring/features.py`, `ai/src/inference/ml_risk.py`, 학습 쪽 `ai/train/train_ml.py`
- 방법: 소스 대조. `make_input_frame`과 점수식 `round(확률 * 100, 1)`은 실행했다. `load_ml_model`의 결측 파일·캐시·재로드는 경로를 바꿔 실행했다. `risk_rf.joblib`은 열지 않았다.
- 판정: 통과 19, 실패 1, 부분 2, 확인불가 0

재현 출력: 감자 `0`·`10`·`11` → `0`·`10`·`10`. 확률 `0.8`·`0`·`1`·`0.1234` → `80.0`·`0.0`·`100.0`·`12.3`. `nan`·`inf` 확률 → `nan`·`inf`.

## 실패·부분

- ALH-0440 부분. `par_price` 0은 `0.0`으로 그대로 들어간다. 양수 강제나 결측 대체가 없다. 배포 CSV에도 액면가 0이 70건 있다.
- ALH-0455 부분. `ml_risk.py`는 시장값을 검사하지 않는다. 미학습 범주 처리는 `train_ml.py`의 `OneHotEncoder(handle_unknown="ignore")`에 있다. 저장된 `risk_rf.joblib` 내부는 열지 않았다.
- ALH-0456 실패. `predict_ml`은 `predict_proba`의 1번 열을 그대로 반올림한다. 실행에서 `nan`과 `inf`가 점수로 반환됐다. 유한하지 않은 예측을 숨기는 분기가 없다.
