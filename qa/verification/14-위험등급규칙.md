# 위험등급규칙 코드검증

- 범위: ALH-0405 ~ ALH-0434
- 대상: `ai/src/scoring/rules.py`, 임계값 `ai/src/core/config.py`의 `SCORE_THRESHOLD_WARNING`
- 방법: 소스 대조. `grade_of`를 직접 실행했다. 모델은 로드하지 않았다.
- 판정: 통과 28, 실패 0, 부분 2, 확인불가 0

재현 출력: 공시 0건에서 `-1`·`0`·`39.9`·`39.99` → `stable`, `40`·`40.0`·`40.1`·`99.9`·`100`·`101` → `warning`. `default`·`suspend`·`rehab` 1건 이상은 점수 10이어도 `danger`. `reduction` 1건 이상은 `warning`. 임계값은 `40.0`이고 비교는 `score >= 40.0`이다.

## 실패·부분

- ALH-0405 부분. `grade_of(-1, 공시 0)`은 `stable`이다. 점수 `-1`을 0~100 밖으로 거부하거나 자르는 코드는 없다.
- ALH-0414 부분. `grade_of(101, 공시 0)`은 `warning`이다. 100 초과도 그대로 등급만 매긴다.
