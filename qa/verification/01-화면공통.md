# 화면공통 코드검증

- 범위: ALH-0001 ~ ALH-0012
- 대상: `front/src/App.tsx`, `front/src/main.tsx`, `front/src/pages/ScreenPage.tsx`, `front/src/pages/ResultPage.tsx`, `front/nginx.conf`
- 방법: 소스 대조. 브라우저를 띄운 실행 증적은 없다.
- 판정: 통과 10, 실패 1, 부분 1, 확인불가 0

## 실패·부분

- ALH-0004 실패. `Routes`에 없는 경로용 `path="*"`가 없다. `/not-existing`은 헤더와 하단 고지만 남고, 경로 오류 문구는 없다.
- ALH-0009 부분. `BrowserRouter`라 주소는 뒤로 가기로 돌아온다. 종목명과 오류는 `ScreenPage`의 `useState`라 결과 화면으로 나가면 사라지고, 돌아오면 기본값 `삼성전자`와 빈 오류로 다시 시작한다.
