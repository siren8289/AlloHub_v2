# 기업진단결과 코드검증

- 범위: ALH-0052 ~ ALH-0080 (29건)
- 대상: `front/src/pages/ResultPage.tsx`, `front/src/api/api.ts`, `front/src/App.tsx`, `back/src/main/java/com/allohub/screen/controller/ScreenController.java`, `back/src/main/java/com/allohub/screen/service/ScreenService.java`, `back/src/main/java/com/allohub/screen/entity/CompanyScreen.java`, `back/src/main/java/com/allohub/global/exception/GlobalExceptionHandler.java`
- 방법: 소스 대조. 브라우저 실행 없음.
- 판정: 통과 25, 실패 2, 부분 2, 확인불가 0

## 실패·부분

- ALH-0061 부분. 당기순이익은 천 단위 숫자만 나온다. `원`이 없다.
- ALH-0071 부분. `기타` 문자는 보이지만 색은 `stable`과 같은 emerald다. 알 수 없는 등급용 스타일이 없다.
- ALH-0074 실패. `abc` 같은 id를 화면이 거르지 않고, 서버는 Long 변환 실패를 500 `서버 오류가 발생했습니다.`로만 답한다. ID 형식 안내가 아니다.
- ALH-0075 실패. `netProfit`이 null이면 `toLocaleString`이 렌더 중에 던진다. 빈 값 안내로 떨어지지 않는다.
