# DL모델추론 코드검증

- 범위: ALH-0457 ~ ALH-0470
- 대상: `ai/src/inference/dl_risk.py`, 피처 `ai/src/scoring/features.py`, 학습 `ai/train/train_dl.py`
- 방법: 소스 대조. `load_dl_model`과 `predict_dl`의 반올림은 가중치 파일 없이 실행했다. `torch.load`는 `map_location="cpu"` 호출만 확인하고 `risk_mlp.pt`는 열지 않았다. sigmoid는 `1/(1+exp(-x))`로 같은 식을 태웠다.
- 판정: 통과 13, 실패 1, 부분 0, 확인불가 0

재현 출력: 로짓 `0` → `50.0`, `10` → `100.0`(확률 0.9999546), `-10` → `0.0`(확률 4.54e-05), `1` → `73.1`. 로짓 `nan` → `nan`. 전처리기 없음·가중치 없음은 각각 `FileNotFoundError`.

## 실패·부분

- ALH-0470 실패. 결측 대체가 없다. 학습 전처리는 `StandardScaler`뿐이고, `predict_dl`은 sigmoid 결과를 검사하지 않는다. 로짓이 `nan`이면 점수 `nan`이 반환된다.
