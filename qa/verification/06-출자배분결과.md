# 출자배분결과 코드검증

- 범위: ALH-0142 ~ ALH-0161 (20건)
- 대상: `front/src/pages/AllocatePage.tsx`, `front/src/api/api.ts`의 `won`·`gradeLabel`, `back/src/main/java/com/allohub/allocation/entity/Allocation.java`, `back/src/main/java/com/allohub/allocation/service/AllocationService.java`, `back/src/main/java/com/allohub/allocation/AllocationCalculator.java`
- 방법: 소스 대조. 브라우저 실행 없음. `won(123456789)`은 Node `toLocaleString("ko-KR")`로 `123,456,789원`을 확인했다.
- 판정: 통과 16, 실패 3, 부분 1, 확인불가 0

## 실패·부분

- ALH-0143 실패. 배분 응답의 `stockCode`를 결과 화면에 그리지 않는다.
- ALH-0144 실패. `market`도 결과 화면에 없다.
- ALH-0157 부분. `lines`가 비어도 예외는 없고 합계 0원과 정합성 문구는 나온다. 빈 목록 안내는 없다.
- ALH-0158 실패. 긴 출자자 이름을 줄바꿈·말줄임으로 가두지 않는다. flex 행이 카드 밖으로 늘어날 수 있다.
